# 有序用电与需求响应政策

有序用电是在电力供应不足时，通过行政、技术、经济手段引导用户错峰、避峰用电的管理措施。

错峰安排原则：先错峰、后避峰、再限电、最后拉闸；优先保障居民生活、农业排灌、医院学校等重要用户用电。

需求响应：供电局提前一天发布邀约，用户在约定时段压减负荷并获得补贴。削峰响应补贴标准为每次每千瓦 12 元，填谷响应补贴标准为每次每千瓦 3 元。

用户基线负荷：需求响应日之前 5 个工作日的同类型日平均负荷，剔除最高值与最低值后取平均。实际压减负荷 = 基线负荷 - 响应日实际负荷，低于邀约量的 80% 视为响应无效。

执行监督：错避峰期间供电局通过用电信息采集系统监测用户执行情况，到位率低于 90% 的用户进行预警通知。
