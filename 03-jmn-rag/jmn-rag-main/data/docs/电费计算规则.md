# 居民阶梯电价计算规则

居民生活用电实行阶梯电价，按年度用电量分三档执行。

第一档：年用电量 0-2760 千瓦时（月均 230 千瓦时），电价 0.56 元/千瓦时。

第二档：年用电量 2761-4800 千瓦时，电价在第一档基础上每千瓦时加价 0.05 元，即 0.61 元/千瓦时。

第三档：年用电量 4800 千瓦时以上部分，电价在第一档基础上每千瓦时加价 0.30 元，即 0.86 元/千瓦时。

阶梯电价按年度周期计算，跨年不清零。低保户、五保户每月可享受 10 千瓦时免费电量，先用电后补贴。

工商业客户执行单一制电价或两部制电价：单一制电价按实际用电量乘以目录电价结算；两部制电价由电度电费加基本电费构成，基本电费按变压器容量或最大需量计收。
