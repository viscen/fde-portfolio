# 业扩报装（新装及增容）办理指南

低压居民新装：客户可通过网上营业厅、营业厅窗口、95598 热线申请。所需材料：身份证、用电地址权属证明。办理时限：受理后 2 个工作日内装表接电。

低压非居民新装：所需材料：营业执照或组织机构代码、用电地址权属证明、经办人身份证。办理时限：受理后 5 个工作日内答复供电方案，具备条件后 5 个工作日内装表接电。

高压新装及增容：供电局在受理后 7 个工作日内答复供电方案（双电源 15 个工作日）。客户受电工程竣工后提出检验申请，供电局 5 个工作日内开展竣工检验，检验合格并签订供用电合同后装表接电。

业扩报装全过程不收取任何费用，严禁指定设计、施工、设备材料单位。
